# JUNKET original production assets

The venues, textures and display models in this behavior pack are generated by
`scripts/minecraft/build_junket_original_world.py`. They are independently
authored and do not contain the licensed map's resource-pack artwork, models,
sounds, datapacks or world data.

The original `JUNKET CRAFT ver1.09` archive remains private. Source-derived files
do not belong in Git or a public release archive. Separately authorized private
builds require their retained private inputs and explicit native-release path;
this public pack does not grant redistribution rights to those materials.

See `docs/minecraft-junket-public-source.md` for public generators, private input
boundaries and the checks that can run without original assets.
