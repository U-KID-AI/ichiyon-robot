# 操作パネルと空メンションの共存

操作パネルは、Botへの空メンションで表示する補助UIです。

空メンションは以前から、管理画面で設定したメンション反応のフォールバックとして使われています。そのため、空メンション時はまず既存のDBランタイム処理を実行します。

処理順は次の通りです。

1. Bot自身や他Botの投稿を除外する。
2. 空メンションならDBランタイム処理を1回だけ実行する。
3. 既存応答があった場合は、その後に操作パネルを別メッセージで添える。
4. 既存応答がなかった場合だけ、操作パネル単体を表示する。
5. 文字付きメンションは従来の音楽、YouTube N連、VC、DBランタイム処理へ進む。

この順序により、名言・おみくじなどの既存フォールバック応答を操作パネルが置き換えないようにしています。
